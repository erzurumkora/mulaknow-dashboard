What this dashboard is

The Mula Know Dashboard is a personal, private, read-only dashboard created by and for the owner of the TikTok account @mulaknow ("we", "us", "the owner"). It exists for one purpose: to let the account owner monitor the performance and upload status of their own TikTok videos in one place.

The dashboard is not a public product. It has no public sign-up, no other users, and no audience-facing features. The only TikTok account it ever connects to is @mulaknow, with that account owner's own authorisation through TikTok's official Login Kit flow.

Access is provided through the official TikTok API (Display API), using only the scopes granted to the "Mula Know Dashboard" app: user.info.basic, user.info.stats, and video.list.

2

Data we access

Through the TikTok API, the dashboard accesses public data belonging to the @mulaknow account only. Nothing else. The complete list is:

DataWhat it includesAPI scope
Basic profile informationDisplay name, username, avatar, bio, and profile link of the @mulaknow accountuser.info.basic
Account statisticsFollower count, following count, total likes received, and total video count of the @mulaknow accountuser.info.stats
Video listThe account's own published videos: title / caption text written by the owner, cover image, share link, and publish datevideo.list
Video countsPer-video numbers only: view count, like count, comment count, and share countvideo.list

All of the above is information that is already publicly visible to anyone who visits the @mulaknow profile on TikTok. The dashboard simply presents the owner's own public numbers back to the owner in a more convenient format.

3

Data we do not access

To be explicit, the dashboard does not access, collect, or store any of the following:

  • Comment content. Only the number of comments per video is shown. The text of comments, and who wrote them, is never read.
  • Other users' data. No data about followers, viewers, commenters, or any other TikTok user is collected in any form.
  • Private account data. No direct messages, drafts, private videos, watch history, search history, or liked-video lists.
  • Credentials. The TikTok password is never seen, requested, or stored. Authorisation happens entirely inside TikTok's own login flow.
  • Device and location data. No device identifiers, IP-based profiling, precise location, contacts, or files from any device.
  • Write actions of any kind. The app holds no permission to post, comment, like, follow, edit, or delete anything.
4

How the data is used

The data described in Section 2 is used for one purpose only: displaying it back to the account owner inside the private dashboard, so the owner can:

  • See which of their own videos have been published and how each is performing;
  • Track view, like, comment, and share counts over time;
  • Plan future uploads based on their own publishing schedule.

The data is not used for advertising, marketing to anyone, profiling, automated decision-making, training machine-learning models, or any purpose unrelated to the owner's own content management.

5

Data sharing

We do not share data with third parties. Specifically:

  • Data is never sold, rented, or traded to anyone.
  • Data is never sent to advertisers, analytics companies, data brokers, or social networks other than TikTok itself (the source of the data).
  • No third-party SDKs, trackers, or embedded services receive any of the data.
  • The only systems involved are TikTok's official API, which provides the data, and the owner's own private dashboard, which displays it.
No exceptions for sale or advertising. There is no business model attached to this dashboard: it is a personal tool with no users to monetise and no data to trade.
6

Cookies and tracking

The dashboard and this policy page use no advertising cookies, no analytics cookies, and no cross-site tracking of any kind. We do not use Google Analytics, Meta Pixel, TikTok Pixel, fingerprinting, or any similar technology.

The only tokens involved are the TikTok API access and refresh tokens issued when the account owner authorises the app. These tokens exist solely so the dashboard can request the owner's own data from TikTok; they are not used to track any person, and they are never shared.

7

Storage and retention

  • Data is retrieved from the TikTok API and displayed to the owner. Any stored copy is limited to the owner's own public video list and counts, kept only so the dashboard can show recent performance without re-requesting it on every view.
  • API access and refresh tokens are stored securely and are used only to fetch the @mulaknow account's data.
  • If authorisation is revoked (see Section 9), the tokens become invalid immediately and any stored copy of the account data is deleted.
  • Because all data involved is the owner's own public data, no other person's information is ever retained.
8

Security

Access to the dashboard is restricted to the account owner. API credentials and tokens are kept in secure storage, are never published, and are never embedded in publicly accessible pages, including this one. All communication with the TikTok API takes place over encrypted HTTPS connections provided by TikTok's official endpoints.

9

Revoking access

The account owner can disconnect this app at any time from within TikTok: Settings and privacy → Security and permissions → Apps and websites → Mula Know Dashboard → Remove access. Removing access immediately invalidates the app's tokens, after which the dashboard can no longer retrieve any data from the account.

Since the dashboard serves a single account whose owner is also its operator, no separate data-deletion request process is needed; revoking access and deleting stored copies is fully within the owner's direct control.

10

Children

The dashboard is a personal tool for an adult account owner. It is not directed at children, offers no sign-up, and collects no data from any person other than displaying the owner's own public account data back to the owner.

11

Changes to this policy

If this policy changes, the updated version will be published at this same URL with a new "Last updated" date. Material changes, such as requesting any additional TikTok API scope, will be reflected here before or at the time they take effect. Continued use of the dashboard after an update means the updated policy applies.

1

Apa itu dashboard ini

Mula Know Dashboard adalah dashboard pribadi yang bersifat read-only, dibuat oleh dan untuk pemilik akun TikTok @mulaknow ("kami", "pemilik"). Tujuannya hanya satu: membantu pemilik akun memantau performa dan status unggahan video TikTok miliknya sendiri dalam satu tempat.

Dashboard ini bukan produk publik. Tidak ada pendaftaran umum, tidak ada pengguna lain, dan tidak ada fitur yang menghadap publik. Satu-satunya akun TikTok yang pernah terhubung adalah @mulaknow, dengan izin pemilik akun itu sendiri melalui alur resmi Login Kit dari TikTok.

Akses diberikan melalui TikTok API resmi (Display API), hanya dengan scope yang diberikan kepada aplikasi "Mula Know Dashboard": user.info.basic, user.info.stats, dan video.list.

2

Data yang kami akses

Melalui TikTok API, dashboard mengakses data publik milik akun @mulaknow saja. Tidak ada yang lain. Daftar lengkapnya:

DataIsinyaScope API

Statistik akunJumlah pengikut, jumlah yang diikuti, total suka yang diterima, dan total video akun @mulaknowuser.info.stats

3

Data yang tidak kami akses

Secara tegas, dashboard ini tidak mengakses, mengumpulkan, atau menyimpan hal-hal berikut:

  • Isi komentar. Hanya jumlah komentar per video yang ditampilkan. Teks komentar dan siapa penulisnya tidak pernah dibaca.
  • Data pengguna lain. Tidak ada data tentang pengikut, penonton, pemberi komentar, atau pengguna TikTok mana pun yang dikumpulkan dalam bentuk apa pun.
  • Data privat akun. Tidak ada pesan langsung (DM), draf, video privat, riwayat tontonan, riwayat pencarian, atau daftar video yang disukai.
  • Kredensial. Kata sandi TikTok tidak pernah dilihat, diminta, atau disimpan. Proses izin sepenuhnya terjadi di dalam alur login milik TikTok sendiri.
  • Data perangkat dan lokasi. Tidak ada pengenal perangkat, profil berbasis IP, lokasi presisi, kontak, atau berkas dari perangkat mana pun.
  • Tindakan menulis apa pun. Aplikasi ini tidak memiliki izin untuk memposting, berkomentar, menyukai, mengikuti, mengubah, atau menghapus apa pun.
4

Cara data digunakan

Data pada Bagian 2 hanya digunakan untuk satu tujuan: menampilkannya kembali kepada pemilik akun di dalam dashboard pribadi, agar pemilik dapat:

  • Melihat video miliknya sendiri yang sudah tayang dan performa masing-masing video;
  • Memantau jumlah views, likes, komentar, dan shares dari waktu ke waktu;
  • Merencanakan unggahan berikutnya berdasarkan jadwal tayang miliknya sendiri.

Data tidak digunakan untuk iklan, pemasaran kepada siapa pun, pembuatan profil, pengambilan keputusan otomatis, pelatihan model machine learning, atau tujuan lain di luar pengelolaan konten milik pemilik akun sendiri.

5

Pembagian data

Kami tidak membagikan data kepada pihak ketiga. Secara khusus:

  • Data tidak pernah dijual, disewakan, atau diperdagangkan kepada siapa pun.
  • Data tidak pernah dikirim ke pengiklan, perusahaan analitik, perantara data, atau jejaring sosial lain selain TikTok itu sendiri (sumber datanya).
  • Tidak ada SDK pihak ketiga, pelacak, atau layanan tertanam yang menerima data apa pun.
  • Satu-satunya sistem yang terlibat adalah TikTok API resmi, yang menyediakan data, dan dashboard pribadi pemilik akun, yang menampilkannya.
Tanpa pengecualian untuk penjualan atau iklan. Dashboard ini tidak punya model bisnis: ini alat pribadi tanpa pengguna untuk dimonetisasi dan tanpa data untuk diperdagangkan.
6

Cookie dan pelacakan

Dashboard dan halaman kebijakan ini tidak menggunakan cookie iklan, cookie analitik, maupun pelacakan lintas situs dalam bentuk apa pun. Kami tidak memakai Google Analytics, Meta Pixel, TikTok Pixel, fingerprinting, atau teknologi sejenis.

Satu-satunya token yang terlibat adalah access token dan refresh token TikTok API yang diterbitkan saat pemilik akun memberi izin ke aplikasi. Token ini hanya ada agar dashboard bisa meminta data milik pemilik akun sendiri dari TikTok; token ini tidak dipakai untuk melacak siapa pun dan tidak pernah dibagikan.

7

Penyimpanan dan retensi

  • Data diambil dari TikTok API dan ditampilkan kepada pemilik akun. Salinan yang disimpan terbatas pada daftar video publik dan angka-angka milik pemilik akun sendiri, hanya agar dashboard bisa menampilkan performa terbaru tanpa harus meminta ulang setiap kali dibuka.
  • Access token dan refresh token API disimpan secara aman dan hanya dipakai untuk mengambil data akun @mulaknow.
  • Jika izin dicabut (lihat Bagian 9), token langsung tidak berlaku dan salinan data akun yang tersimpan akan dihapus.
  • Karena seluruh data yang terlibat adalah data publik milik pemilik akun sendiri, tidak ada informasi milik orang lain yang pernah disimpan.
8

Keamanan

Akses ke dashboard dibatasi hanya untuk pemilik akun. Kredensial dan token API disimpan di penyimpanan yang aman, tidak pernah dipublikasikan, dan tidak pernah disematkan di halaman yang bisa diakses publik, termasuk halaman ini. Seluruh komunikasi dengan TikTok API berlangsung melalui koneksi HTTPS terenkripsi di endpoint resmi TikTok.

9

Mencabut akses

Pemilik akun dapat memutus aplikasi ini kapan saja dari dalam TikTok: Pengaturan dan privasi → Keamanan dan izin → Aplikasi dan situs web → Mula Know Dashboard → Hapus akses. Menghapus akses langsung membuat token aplikasi tidak berlaku, dan setelah itu dashboard tidak bisa lagi mengambil data apa pun dari akun tersebut.

Karena dashboard ini melayani satu akun yang pemiliknya sekaligus operatornya, tidak diperlukan proses permintaan penghapusan data yang terpisah; pencabutan akses dan penghapusan salinan data sepenuhnya berada dalam kendali langsung pemilik akun.

10

Anak-anak

Dashboard ini adalah alat pribadi untuk pemilik akun yang sudah dewasa. Dashboard ini tidak ditujukan untuk anak-anak, tidak menyediakan pendaftaran, dan tidak mengumpulkan data dari siapa pun selain menampilkan kembali data akun publik milik pemiliknya kepada pemiliknya sendiri.

Penggunaan dashboard setelah pembaruan berarti kebijakan versi terbaru yang berlaku.
